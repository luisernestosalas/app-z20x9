# Documentación Técnica - CRM App Z20X9

## Información General

**Aplicación:** Sistema CRM con gestión de clientes y notas
**Stack Tecnológico:** HTML + JavaScript (Frontend puro)
**Repositorio:** https://github.com/luisernestosalas/app-z20x9
**URL de Producción:** https://app-z20x9-bepgkf501-luisernestosalas-2775s-projects.vercel.app
**Plataforma de Deployment:** Vercel

## Arquitectura

### Frontend
- **HTML5:** Estructura y marcado semántico
- **JavaScript Vanilla:** Lógica de aplicación, manipulación DOM
- **CSS:** Estilos y diseño responsivo (implícito en aplicaciones web)

### Características Principales
- Gestión de clientes
- Sistema de notas asociadas
- Interfaz de usuario intuitiva
- Aplicación Single Page Application (SPA)

## Funcionalidades

### Módulo de Clientes
- Crear nuevos clientes
- Listar clientes existentes
- Editar información de clientes
- Eliminar clientes

### Módulo de Notas
- Crear notas asociadas a clientes
