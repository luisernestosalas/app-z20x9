# Manual de Usuario - CRM con Clientes y Notas

## ¿Qué es esta aplicación?

Es un sistema simple para gestionar clientes y sus notas. Te permite guardar información de contacto y llevar un registro de interacciones con cada cliente.

## Cómo acceder

**URL:** https://app-z20x9-bepgkf501-luisernestosalas-2775s-projects.vercel.app

Solo necesitas un navegador web. No requiere instalación.

## Funciones principales

### 1. Agregar un cliente nuevo
- Haz clic en "Agregar Cliente" o botón similar
- Completa los datos:
  - Nombre
  - Empresa
  - Teléfono
  - Email
  - Otros campos disponibles
- Guarda la información

### 2. Ver lista de clientes
- En la pantalla principal verás todos tus clientes
- Puedes buscar por nombre o empresa
- Haz clic en un cliente para ver más detalles

### 3. Editar información de cliente
- Selecciona el cliente que quieres modificar
- Haz clic en "Editar"
- Cambia los datos necesarios
- Guarda los cambios

### 4. Agregar notas a un cliente
- Entra al perfil del cliente
- Busca la sección de "Notas"
