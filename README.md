# CRM App Z20X9

Una aplicación CRM simple y eficiente para gestionar clientes y notas, construida con HTML y JavaScript vanilla.

## 🚀 Demo

**URL de la aplicación:** [https://app-z20x9-bepgkf501-luisernestosalas-2775s-projects.vercel.app](https://app-z20x9-bepgkf501-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ Gestión completa de clientes
- 📝 Sistema de notas asociadas a clientes
- 💾 Almacenamiento local en el navegador
- 📱 Diseño responsive
- ⚡ Interfaz rápida y ligera
- 🔍 Búsqueda y filtrado de clientes

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Almacenamiento:** LocalStorage
- **Deploy:** Vercel
